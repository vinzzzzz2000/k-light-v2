# K-Light 💡

POC Treasury Management avec Powens Open Banking.

## Installation

### 1. Backend

```powershell
cd backend
notepad .env          # Mets ton POWENS_CLIENT_SECRET
npm install
npm start
```

### 2. Frontend (nouveau terminal)

```powershell
cd frontend
npm install
npm run dev
```

### 3. Ouvre http://localhost:3000
